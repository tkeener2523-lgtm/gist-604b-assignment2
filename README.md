## Overview
This repository is a collection of tutorial projects for the use of QGIS desktop application. GQZ files and screenshots of those files are included to demonstrate the ability to use and document workflows with QGIS. It shows the ability to perform powerful GIS operations with open-source software. What I learned in this module was:
- Creating a shareable map layout
- Working with projections
- Working with attribute data
- Importing tabular data
- Styling vector data
- Styling and analyzing raster data
- Performing table joins
- Performing spatial joins
- Performing spatial queries
- Calculating geometry statistics

## Software Environment
QGIS Version: 4.2.3\

Plugins used for Analysis: Included with standard download of QGIS

## Reflection

This module was very helpful in introducing the QGIS desktop application. As never using this application before, I was able to see the tremendous capabilities an open-source project can deploy with spatial data. The tutorials gave me a clearer picture on how to use the application, import various types of data, performing spatial analysis, and styling maps for public use. The most challenging part of this project was learning where all the different functions and applications were located within the software. With this being an open-source software, it did not seem as polished as ArcGIS Pro, but it had all the same and if not more capabilities for handling spatial data. I anticipate using these skills to continue exploring QGIS, as well as, exploring different types of open-source GIS softwares.
